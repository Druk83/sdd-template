# .source — исходные материалы проекта

В этот каталог разработчик помещает исходные материалы проекта для анализа:
описания предметной области, процессы, ограничения и дополнительные сведения.

Материалы из `.source/` не являются шаблонами фреймворка и не заменяются при
установке или обновлении SDD Framework.
