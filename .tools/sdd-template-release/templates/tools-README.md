# Переносимые инструменты SDD Framework

В этой папке находятся инструменты, необходимые проекту-потребителю.

В установленном проекте корень фреймворка имеет путь
`.agents/sdd-template-{{VERSION}}/`. Сокращённые пути каталогов фреймворка в
его документации разрешаются относительно этого корня. Результаты работы
инструментов (`.tasks/`, `docs/`) сохраняются в корне проекта-потребителя.
Журналы работы Framework сохраняются только по явному запросу разработчика в
`.agents/sdd-template-{{RELEASE_DIR}}/.chatlog/`.

- `check-encoding` — проверка UTF-8 и управляющих символов;
- `pdd` — сканирование `@todo` и обновление реестра задач;
- `plantuml-render` — рендеринг поддерживаемых диаграмм;
- `requirements-profile` — выбор профиля требований этапа [3] и проверка результата;
- `agent-logic` — обязательный встроенный компилятор и анализатор.

Сборщик `sdd-template-release` остаётся в мета-репозитории и в релизный пакет
не входит.

Полный реестр находится в
`.agents/sdd-template-{{VERSION}}/.tools/registry.json`. Перед запуском инструмента
агент проверяет его наличие и инструкцию в соответствующей папке.

Runtime-данные и локальные отчёты `agent-logic` хранятся в
`tmp/agent-logic/.runtime/` относительно корня проекта-потребителя. Каталог `tmp/`
игнорируется Git; не удаляйте его целиком при очистке данных инструмента.
