# requirements-profile — выбор профиля требований

> Версия инструмента: `0.1.0`.

Инструмент проверяет каталог профилей и определяет процедуру этапа [3] по
подтверждённому результату этапа [2]. Он читает проектные документы и не
записывает их.

## Быстрый старт

Из корня Framework:

```text
python .tools/requirements-profile/requirements_profile.py registry
python .tools/requirements-profile/requirements_profile.py resolve --project-root <корень-проекта>
python .tools/requirements-profile/requirements_profile.py check-result --project-root <корень-проекта>
```

В установленном проекте запускай файл инструмента из
`FRAMEWORK_ROOT/.tools/requirements-profile/`, а `--project-root` указывай на
корень проекта-потребителя.

## Входы и выходы

- Источник профилей: `.requirements/требования/профили.json` из того же пакета.
- Выбор проекта: `docs/requirements/обоснование выбора.md`, поле
  `**Профиль требований:** <profile-id>`.
- Совместимость: старое поле `**Выбранный стандарт:** ГОСТ 19/34` распознаётся;
  если нет документа или выбора, используется `gost-19`.
- `resolve` возвращает JSON с инструкцией, выходным документом и источником;
  для `iso-29148` также возвращается `source_document_url` полного PDF.
- `check-result` проверяет метаданные и заголовки выбранного H8-документа.
  Для `iso-29148` дополнительно проверяются ссылка на источник, выбор SRS/SyRS
  по `scope`, готовое оглавление Framework с привязками `[ISO ...]` и
  `[Framework]` для собственных разделов,
  отсутствие заявления о полном соответствии, `document_readiness` и строки
  покрытия всех применимых пунктов выбранной ветки. В режиме `draft` допускается
  статус `gap`; в режиме `ready_for_review` открытые `gap`, влияющие на текущий
  H8, и `TBD/TBS/TBR` запрещены. Процедура H6 также передаёт агенту полный
  контекст разделов 1–8,
  9.1–9.6 и приложений A–C; автоматическая проверка не подменяет чтение
  этих разделов и не подтверждает содержательную корректность результата.

При неизвестном профиле, конфликте двух полей или неподдерживаемом старом
стандарте инструмент завершится ошибкой и попросит явный выбор.
