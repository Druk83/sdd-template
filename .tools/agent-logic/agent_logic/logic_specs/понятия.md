# Понятия и определения

Проверь, что ключевые термины имеют устойчивое значение, а объём и содержание
понятия не меняются по ходу рассуждения. Отмечай неопределённость, омонимию,
подмену понятия, круговое или слишком широкое определение и нарушение правила
соразмерности. Отсутствие определения само по себе является вопросом к
контексту, а не доказательством ошибки.
