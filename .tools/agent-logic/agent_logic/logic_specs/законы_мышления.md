# Законы мышления

Проверь применимость закона тождества, непротиворечия, исключённого третьего и
достаточного основания. Учитывай предметную область и модальность: смена
контекста может быть допустимым уточнением, а не нарушением тождества.
Недостаток основания фиксируй как степень обоснованности, не как доказанную
ложность утверждения.
