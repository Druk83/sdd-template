# Дедукция и силлогизмы

Для дедуктивного вывода укажи посылки, заключение и форму перехода. Для
категорического силлогизма проверь число терминов, распределённость терминов,
допустимость отрицательных и частных посылок и связь заключения с посылками.
Для условных и разделительных выводов проверь направление импликации и полноту
альтернатив. Если форма не восстанавливается однозначно, верни несколько
интерпретаций и не выбирай одну без основания.
