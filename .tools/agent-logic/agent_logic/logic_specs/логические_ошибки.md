# Каталог логических ошибок

Используй открытый каталог и добавляй точное описание, если ошибка не входит в
перечень. Базовые семейства: `ignoratio elenchi` (подмена тезиса), `petitio
principii` (предположение основания), `circulus in demonstrando` (порочный
круг), `argumentum ad hominem`, `post hoc ergo propter hoc`, поспешное
обобщение (`fallacia fictae universalitatis`), ложная аналогия, утверждение
следствия, отрицание основания, `quaternio terminorum`, `a dicto secundum
quid`, сдвиг коллективного/распределительного смысла и ложная дилемма.

Не присваивай ошибку только по ключевому слову: укажи нарушенное правило,
фрагмент и альтернативное чтение, если оно возможно.
