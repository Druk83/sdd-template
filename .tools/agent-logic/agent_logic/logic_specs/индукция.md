# Индукция и аналогия

Отличай полную индукцию от неполной. Для обобщения проверь размер и
репрезентативность основания, пропущенные случаи и переход от наблюдения к
универсальному выводу. Для причинности отделяй корреляцию от причины и проверяй
альтернативные объяснения. Для аналогии укажи сходства, существенное различие
и силу переноса свойства; не считай внешнее сходство достаточным основанием.
