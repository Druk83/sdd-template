# Инструкции для агента agent-logic

## Установка готового пакета

Если пользователь указал каталог готового экспорта `agent-logic`, считайте его проверенным переносимым пакетом.

1. Скопируйте каталог целиком в `.tools/agent-logic` проекта-потребителя.
2. Добавьте без изменений содержимое `registry-entry.json` в `.tools/registry.json`.
3. Прочитайте путь из поля `instructions` добавленной записи реестра.
4. Проверьте `manifest.json` и запустите точку входа из реестра с `--help`.

Запрещено пересоздавать, генерировать по аналогии или переписывать исходный код, wrappers, README и манифест пакета. Создание нового экспорта выполняется только упаковщиком в исходном репозитории инструмента.

Если `.tools/agent-logic` уже существует, не заменяйте его без явного разрешения пользователя. Сначала сообщите о конфликте версии или содержимого.

## Обязательная проверка по запросу пользователя

Если пользователь просит проверить или проанализировать документ, агент обязан создать Markdown-отчёт проверки в `.tools/agent-logic/.runtime/exports/<compilationId>/`. Файл отчёта не создаётся в `.tasks/` и не заменяет существующий результат.

1. Сохраните исходный текст запроса и время его регистрации в ISO 8601 со смещением UTC.
2. Запустите `compile` с `--format md`, `--request`, `--requested-at`, явными `--output` и `--write`.
3. Путь `--output` должен находиться только в `.tools/agent-logic/.runtime/exports/<compilationId>/`.
4. Не добавляйте `--replace`, если пользователь отдельно не разрешил замену существующего отчёта.
5. В сообщении человеку укажите путь к созданному отчёту, его статус и краткий вывод из `agent_context.user_guidance`.
6. Если `user_guidance.mode=NO_ACTION_REQUIRED`, прямо сообщите: «Действия по результату проверки не требуются». Не ищите, что можно исправить дополнительно.
7. Если `user_guidance.mode=REVIEW_REQUIRED`, перечислите только `required_actions`: правило, источник и безопасный следующий шаг.
8. Если `user_guidance.mode=HUMAN_DECISION_REQUIRED`, задайте только `human_question` и приведите карточку решения; не выбирайте вариант и не предлагайте редакторскую замену текста.
9. `observations` являются справочным контекстом. Запрещено выдавать их за ошибку, GAP, обязательное действие, вопрос человеку или рекомендацию правки. Не изменяйте исходный документ автоматически.

Пример структуры вызова:

```text
python .tools/agent-logic/agent-logic.py compile <путь-к-документу> --format md --request <исходный-запрос> --requested-at <ISO-8601> --output .tools/agent-logic/.runtime/exports/<compilationId>/<имя>.agent-logic.md --write
```

Если применимые правила проекта-потребителя запрещают создание файла без отдельного разрешения, сообщите это человеку и покажите команду; не обходите правила верхнего уровня.
