# Техническая документация пользовательского интерфейса (UI)

Этот каталог содержит методику создания артефактов пользовательского интерфейса
в `docs/requirements/пользовательский-интерфейс/`.

Источником UI-паттернов является только:

`https://github.com/Druk83/ui-patterns.git`

Порядок работы:

1. Сформировать и подтвердить пул экранов (screen pool).
2. Предложить и подтвердить матрицу областей отображения (viewport matrix).
3. Выбрать кандидатов UI-паттернов (pattern candidates) и переиспользуемые
   шаблоны экранного UI (reusable screen UI templates).
4. Создать спецификации экранов (screen specifications) и трассируемость (traceability).
5. Создать и проверить живые эталонные прототипы (live reference prototypes).

При отсутствии UI агент фиксирует `gap`, предлагает варианты и использует
`not_applicable` только после подтверждения отсутствия UI.

Проектные макеты хранятся в `docs/requirements/пользовательский-интерфейс/references/`.
Production code, project API и реальные product data в этот каталог не включаются.
