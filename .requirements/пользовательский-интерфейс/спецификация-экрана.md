Для каждого визуального артефакта укажи `shell_binding` со статусом `selected`,
`proposed` или `gap`. Для невизуального представления укажи
`not_applicable` с обоснованием. При `selected` и `proposed` зафиксируй URL
и точную ревизию каталога оболочек, `shell_id`, его `shell_version`, `viewport_id`
и размеры оболочки в CSS px; для стандартной библиотеки Framework используй
официальный репозиторий `https://github.com/Druk83/sdd-template.git` и `source_commit`
из `FRAMEWORK_ROOT/release-manifest.json`. Сам `shell_id` должен существовать
в библиотеке `FRAMEWORK_ROOT/.tools/ui-screen-scaffold/shells/shell-library.json`.
Геометрия должна совпадать с viewport артефакта и пула. Если подходящей
оболочки нет, используй `gap`, не заменяй её приблизительным макетом.
